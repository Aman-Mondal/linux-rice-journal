# Linux Rice Journal

A personal collection of my Arch Linux and Hyprland rice configurations, desktop screenshots, and experiments.

This repository documents my journey into Linux customization — starting with tutorial-inspired setups and gradually evolving into configurations I understand, modify, and make my own.

## Rice 01 — Crimson

My first documented rice, featuring a black-and-crimson wallpaper, translucent Kitty terminals, rounded corners, blur, and a customized Waybar.

## Goals

- Document my Linux customization journey.
