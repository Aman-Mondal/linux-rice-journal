# Rice 01 — Crimson

My first documented Hyprland rice on Arch Linux. Built around a black-and-crimson wallpaper, translucent Kitty terminals, subtle blur, rounded corners, and warm accent colors.

The goal was to create a minimal desktop that looks good while staying practical for everyday development.

## Environment

| Component | Setup |
|---|---|
| OS | Arch Linux |
| Window Manager | Hyprland |
| Status Bar | Waybar |
| Terminal | Kitty |
| Application Launcher | Rofi |
| Notifications | SwayNC |
| Lock Screen | Hyprlock |
| Idle Management | Hypridle |
| Shell | Zsh |
| GTK Theme | adw-gtk3-dark |
| Icon Theme | Papirus |

## Visual Style

- Black-and-crimson wallpaper
- Translucent terminal windows with blur
- Rounded corners and subtle borders
- Orange active-window accent
- Pink and cyan terminal prompt accents
- Minimal Waybar with compact status modules

## Included Configurations

This rice contains the configurations and scripts I use for my desktop:

- `hypr/` — Hyprland, lock screen, and idle configuration
- `waybar/` — Status bar layout and styling
- `kitty/` — Terminal appearance and behavior
- `rofi/` — Application launcher styling
- `swaync/` — Notification center styling
- `scripts/` — Custom scripts, including the power menu

Only the configurations relevant to this rice are included.
